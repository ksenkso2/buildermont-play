# Buildermont — playable build

A factory game: extract resources, run them along conveyor belts into workshops and factories, research the tech tree and build the Earth Teleporter.

**Play: https://ksenkso2.github.io/buildermont-play/**

It runs entirely in your browser — the simulation in a Web Worker, your world saved in your own browser's storage. There is no server, no account, and nothing is shared between players. The page installs to a home screen as an app and works with no network.

This repository holds generated files only, produced by `npm run build:static` in the (private) source repository.
